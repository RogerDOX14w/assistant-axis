# Two base-persona candidates per axis; downstream tooling can grep
# for indented role names per ## section.

# 2026-05-17 manual override on 5 RLHF-saturated axes (helpful,
# harmless, honest, truthful, guileless): the v1 steering experiments
# showed the model defaults to the virtuous pole on these axes, so
# steering toward virtuous has ~zero headroom.  Picking the 2nd role
# distinctly UN-virtuous gives a meaningful baseline so the steering
# can actually move the response toward virtuous.  3 of the 5 axes
# have no good non-goal-pool candidates (the non-goal pool excludes
# morally-valenced roles by construction), so we fall back to goal-
# pool roles -- those sections are tagged ``2nd from goal pool for
# headroom`` instead of ``base from non_goal pool``.  See the
# question_set_v1 summary + 2026-05-17 conversation for the full
# reasoning + ranked candidate tables.  These overrides will be
# clobbered if tools/pick_base_personas.py is re-run -- preserve
# manually or extend the picker.
